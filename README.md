# bibimpapi-site

The website at **https://bibimpapi.com**, served by GitHub Pages.

- `index.html`: the homepage
- `snail/`: the web build of Murder Snail. **Don't edit it by hand.** It's generated by `tools/publish_web.ps1` in the `murder-snail` repo.
- `design/`: the Modular POS design gallery (the workshop page). **Don't edit it by hand.** It's a build of `app/web/workshop.html` from the `Modular-POS` repo, made with relative paths (`base: "./"`).
- `CNAME`: tells GitHub Pages this site is bibimpapi.com
- `.nojekyll`: tells GitHub Pages to serve files as they are
